# Mini-projets API — IPSSI

Ce dépôt regroupe deux mini-projets Python réalisés en groupe.

## Projet 1 — TMDB

Consultation de films via l’API TMDB, gestion des erreurs,
simulation de forte charge, cache, import SQLite et interface Streamlit.

Le code et les instructions sont dans [projet_tmdb](projet_tmdb/README.md).

## Projet 2 — PokéAPI

Consultation et comparaison des statistiques de Pokémon,
analyse par type et simulation de combat.

Projet en cours de réalisation.
